# Conversor de Unidades

**Convierte entre diferentes unidades de forma rápida y precisa**

## Descripción

Aplicación web que permite convertir entre diferentes unidades de medida en 4 categorías: longitud, peso, temperatura y volumen.

## Características

- **4 categorías**: Longitud, Peso, Temperatura, Volumen
- **16+ unidades** por categoría
- **Conversión en tiempo real** mientras escribes
- **Botón de invertir** unidades
- **Tabla de referencia** rápida
- **Precisión** hasta 6 decimales

## Uso

1. Abre `index.html`
2. Selecciona la categoría (longitud, peso, temperatura, volumen)
3. Ingresa el valor a convertir
4. Selecciona las unidades de origen y destino
5. ¡Listo! El resultado aparece automáticamente
